# 墨戏 · 一字一画

打一个字，长出一幅水墨。免构建的原生 HTML/Canvas 互动页面，可用作识字、识拼音的互动课件。

## 用法

直接用浏览器打开 `index.html` 即可，不需要构建、不需要服务器、不联网。

1. 在纸上**点一下**定下落笔处（会出现一个圆形准星）；
2. 用系统输入法**打出一个汉字**，它会在那一点洇开成一幅水墨；
3. 不点直接打字，则按版面自动找位置，一个字一幅画，越排越密；
4. 鼠标划过纸面可搅动墨色；输入 `风 雨 雪 雷 晴` 会切换天气与风。

工具条：`字表`（识字台，点字即落）、`存画`（导出 PNG）、`清纸`、`有声`。
`Backspace` 擦掉最后一幅（其余的画保持原样），`Esc` 收起准星/字表。
开着“有声”时，落字后会用系统自带的中文语音读出来；点拼音卡上的字或组词可以再听一遍。

## 玩法设计

- 每个汉字带拼音、声调、释义、组词，落字后弹出字卡（`js/pinyin.js`，182 字）。字表以外的字也能显示拼音（本地 `vendor/pinyin-pro.js`）。
- 拼音按小学课本的规则拆分：16 个整体认读音节（zhi chi shi ri zi ci si yi wu yu ye yue yuan yin yun ying）不拆；j q x y 后面的 u 还原成 ü（如“雪”拆成 x + üě）；并标出第几声。
- 字义决定画面：`山` 生远山，`鱼` 生游鱼，`柳` 生垂柳，`伞` 生油纸伞……共 81 个题材画笔（`js/motifs.js`）。
- 画面不是贴图：每次都由毛笔引擎（`js/draw.js`）现场生成，含枯笔、飞白、洇墨、随机的枝干与叶脉，所以同一个字每次都不一样。每幅画会记住自己的随机种子，撤销或改窗口大小后重画出来仍是同一幅，不会拉伸变形。
- 生画过程是一段洇墨过渡：画先在离屏纸上完成，再由中心一团团湿墨向外扩圈显形，边缘羽化、湿意渐干，最后无跳变地落到宣纸上（`js/app.js`）。
- 背景是一层稳定的流体墨模拟（`js/ink.js`，Stam stable fluids），纸纹与暗角在 CSS 层。

## 目录

```
index.html          页面与画布层栈
css/style.css       宣纸、UI、准星与颗粒/暗角
vendor/pinyin-pro.js 字表以外汉字的拼音（MIT）
js/pinyin.js        汉字字典：拼音 / 声调 / 释义 / 组词 / 题材
js/draw.js          毛笔引擎：笔锋、枯笔、点苔、泼墨、题字
js/motifs.js        81 个题材画笔（山水花鸟、Weather、器物）
js/ink.js           流体墨模拟
js/scene.js         天气、远山、云雾、飞鸟、游鱼等活景
js/audio.js         落笔与风声雨声（WebAudio，可关）
js/app.js           主控：输入→落字→洇墨生画→动景→出声
```

## 说明

- 除 `vendor/pinyin-pro.js`（[pinyin-pro](https://github.com/zh-lx/pinyin-pro)，MIT）外没有第三方依赖，仍然不需要联网。
- 全部为脚本级全局对象（`MoDraw`/`MoMotifs`/`MoInk`/`MoZi`/`MoScene`/`MoAudio`/`MoApp`），刻意不用 ES Module 与打包器，以便 `file://` 直接运行。
- 交互与画面是对同一种玩法的独立实现，灵感来自短视频里的「打字生水墨」创意。
